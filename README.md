# Telectro Membership Demo

A responsive public website for Telectro's five-month membership program.

## Demo features

- Membership signup for name, address, email and mobile number
- ₦75,000 membership presentation
- Payment confirmation screen
- Demo WhatsApp handoff
- Responsive mobile and desktop interface
- No backend or personal data storage

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 4173
```

Visit `http://localhost:4173`.

## Vercel deployment

Import this repository in Vercel and use the default static-site settings. There is no build command required.

## Before launch

- Replace `2348000000000` with your real WhatsApp number
- Add the real receiving bank details
- Add login and admin functionality with a database
- Configure password hashing and secure sessions
- Add terms, privacy and refund policy pages
